curl 8.23.0 for tOS
====================

bin/curl and lib/libcurl.so.4 are curl 8.23.0 built from the release tarball, unmodified, with HTTP and
HTTPS only (OpenSSL for TLS, zlib), against the openssl, zlib and ca-certificates packages tpkg installs
first. License: the curl license (LICENSE).
glibc: these programs are linked dynamically against the GNU C Library, which tOS's base system carries in /lib64 and /lib/x86_64-linux-gnu (versions, licenses and sources in LICENSES.txt there).

Source: https://curl.se/download/curl-8.23.0.tar.xz
Built with:
  ./configure --prefix=... --enable-shared --disable-static --with-openssl --with-zlib --without-libpsl \
    --without-brotli --without-zstd --without-nghttp2 --without-libidn2 --without-librtmp --without-libssh2 \
    --without-libssh --disable-ldap --disable-ldaps --disable-rtsp --disable-dict --disable-telnet \
    --disable-tftp --disable-pop3 --disable-imap --disable-smtp --disable-gopher --disable-mqtt --disable-smb \
    --disable-ftp --disable-docs --disable-manual --disable-ntlm \
    --with-ca-bundle=/system/pkg/ca-certificates/cacert.pem \
    LDFLAGS=-Wl,-rpath,/system/pkg/openssl/lib:/system/pkg/zlib/lib
Then the run-time library path of bin/curl was set to /system/pkg/curl/lib:/system/pkg/openssl/lib:/system/pkg/zlib/lib (patchelf) and the files stripped.
